# quiver_achievement

Achievements for Starknet games: tasks, tiers, claim. Pure Cairo and Starknet, no Dojo.

**Not implemented yet.** Today the package holds only its bounds, in
`quiver_achievement::constants` (`MAX_TASKS`, `ACHIEVEMENTS_PER_PAGE`, `MAX_PAGES`,
`MAX_ENTRIES`). The logic and the component are written by ARC-04. The accepted API is in
[ARC-01 §3](../../docs/research/ARC-01-quest-achievement.md).
